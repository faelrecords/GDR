# Editor visual da landing page GDR

1. Abra um terminal nesta pasta.
2. Na primeira vez, execute `npm install`.
3. Execute `npm run editor`.
4. O editor abrirá em `http://localhost:8080/editor.html`.

As alterações são salvas automaticamente neste navegador. O botão **Salvar arquivos** permite escolher a pasta do projeto e gravar `index.html` e `styles.css`. Para preservar os arquivos atuais, use **Baixar cópia**.

O editor precisa ser aberto pelo servidor local; abrir `editor.html` diretamente não permite carregar os arquivos da página.
